# market-data

미국장 마감 후 매일 자동으로 시세를 받아 저장하고, 토니크로스 매매기준 지표를 계산합니다.

- 수집 종목: VIX, VIX3M, VXX, SPX(^GSPC), SPY, QQQ, SOXX, SOXL
- 실행: 매일 한국시간 06:30 (GitHub Actions `시세 수집`), Actions 탭에서 수동 실행도 가능
- 결과
  - `data/<종목>.csv`: 최근 5년 일봉
  - `data/summary.json`: 시장 국면(VIX 주봉 스토캐스틱, VXX DMI, VIX/VIX3M)과 종목별 MACD(19,39,9)·이평·주봉 MFI 등

주봉 값은 마감된 주봉 기준이며, 진행 중인 주의 값은 `_진행중` 항목으로 따로 기록합니다.

## 옵션 감마 (QQQ·SOXL)

`scripts/options_gex.py`가 시세 수집 직후 옵션체인(행사가별 미결제약정·내재변동성)을 받아 계산합니다.

- 결과: `data/summary.json`의 `options` 항목, `data/options/<종목>.json`
- 항목: 넷감마($/1%), 제로감마 플립, 콜월(현재가 위 넷감마 최대 행사가), 풋월(현재가 아래 넷감마 최소 행사가), 맥스페인, 감마·OI 상위 행사가, 풋콜 OI 비율
- 범위: 가까운 만기 3개 각각, 9일 이내 만기 합산(`1주합산`), 90일 이내 전체 합산(`전체합산`)
- 가정: 딜러가 콜은 롱·풋은 숏(OptionCharts 등 무료 사이트와 같은 방식). firmtape 등과 플립이 1~2달러 다를 수 있음
- OI는 거래소가 장 시작 전에 갱신하므로 전 거래일 장 시작 시점 물량입니다
